# Khanfar Phone Tool

![Khanfar Phone Tool](1.ico)

## Overview
Khanfar Phone Tool is a powerful digital forensics utility designed for Android device data extraction and analysis. This tool provides law enforcement, forensic investigators, and security professionals with a streamlined interface to extract, catalog, and manage digital evidence from Android devices.

## Key Features

### Device Connection
- **ADB Integration**: Seamlessly connect to Android devices using Android Debug Bridge
- **Multiple Device Support**: Works with a wide range of Android devices and manufacturers
- **Storage Path Auto-Detection**: Automatically identifies the correct storage location on different device models

### File Extraction
Extract files from connected devices based on file type filters:
- **Images**: JPG, JPEG, PNG, GIF, BMP
- **Videos**: MP4, AVI, MKV, MOV
- **Documents**: PDF, DOC, DOCX, TXT, XLS, XLSX, KEY
- **Audio**: MP3, WAV, FLAC, AAC
- **Archives**: ZIP, RAR, 7Z, TAR

### Evidence Management
- **Organized File Storage**: Automatically organizes extracted files by device ID and file type
- **Real-time Progress Tracking**: Visual progress indicators during extraction and deletion operations
- **Detailed Logging**: Comprehensive logging of all operations for evidence integrity

### Secure Data Handling
- **Selective File Deletion**: Securely remove selected file types from devices when needed
- **Confirmation Systems**: Built-in confirmation prompts to prevent accidental data deletion

## How to Use

### Quick Start Guide

1. **Launch the Application**: Run the Khanfar Phone Tool executable
2. **Start ADB Server**: Click "Start Server" button to initialize ADB services
3. **Connect Device**: Connect your Android device via USB and enable USB debugging
4. **Establish Connection**: Click "Connect Phone" to establish a connection with the device
5. **Verify Connection**: Use "Verify Connection" to ensure proper communication with the device
6. **Auto-Detect Storage**: Click "Auto-Detect" to identify the correct storage path on the device
7. **Select File Filters**: Check the file types you wish to extract (Images, Videos, etc.)
8. **Extract Files**: Click "Extract Files" to begin the extraction process
9. **Monitor Progress**: Watch the progress bar and log window for real-time updates
10. **Access Files**: Click "Browse Files" to open the folder containing extracted files

### Requirements

- Windows Operating System
- USB connection to Android device
- USB Debugging enabled on the Android device

### Tips for Optimal Use

- Ensure the Android device remains connected throughout the extraction process
- For devices with large storage, extraction may take significant time
- Keep the tool updated to ensure compatibility with the latest Android versions
- Extracted files are stored in the "db" folder, organized by device serial number and file type
